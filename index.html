How to use an ID

Copy-paste snippets for animations and audio, plus how to swap a default animation.

Play an animationLuau
local Players = game:GetService("Players")
local player = Players.LocalPlayer
local character = player.Character or player.CharacterAdded:Wait()
local humanoid = character:WaitForChild("Humanoid")
local animator = humanoid:WaitForChild("Animator")

local anim = Instance.new("Animation")
anim.AnimationId = "rbxassetid://507771019" -- default dance

local track = animator:LoadAnimation(anim)
track:Play()
Replace a default animationLuau
local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
  player.CharacterAdded:Connect(function(character)
    local animate = character:WaitForChild("Animate")
    -- swap the walk cycle for your own animation ID
    animate.walk.WalkAnim.AnimationId = "rbxassetid://YOUR_ID"
  end)
end)
Play a sound (Studio)Luau
local sound = Instance.new("Sound")
sound.SoundId = "rbxassetid://142376088" -- Raining Tacos
sound.Volume = 1
sound.Parent = workspace
sound:Play()

Use a sound in-game (boombox)

  1. Join a game with a boombox, radio or car stereo (Brookhaven, Berry Avenue, Catalog Heaven).
  2. Equip the music item.
  3. Paste the plain number into its input box and press play.

Some games sell the boombox as a game pass; some disable custom audio entirely.
