Animation IDs

The numeric ID of an animation asset. Default character moves (idle, walk, run, jump, fall, climb, swim) and emotes (wave, point, dance, laugh, cheer) each have one. Set it in a script with animation.AnimationId = "rbxassetid://ID", or swap the value inside the character's Animate script.

Sound IDs (a.k.a. audio / music / boombox IDs)

The numeric ID of an audio asset. The same number works in a Sound object in Studio, in an in-game boombox or radio, or a car stereo — you just paste the raw number. This is what most players mean by "song IDs".

How to use an ID

Play an animation (script)

local Players = game:GetService("Players")
local player = Players.LocalPlayer
local character = player.Character or player.CharacterAdded:Wait()
local humanoid = character:WaitForChild("Humanoid")
local animator = humanoid:WaitForChild("Animator")

local anim = Instance.new("Animation")
anim.AnimationId = "rbxassetid://507771019" -- default dance

local track = animator:LoadAnimation(anim)
track:Play()

Replace a default animation

local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
  player.CharacterAdded:Connect(function(character)
    local animate = character:WaitForChild("Animate")
    -- swap the walk cycle for your own animation ID
    animate.walk.WalkAnim.AnimationId = "rbxassetid://YOUR_ID"
  end)
end)

Play a sound (Studio)

local sound = Instance.new("Sound")
sound.SoundId = "rbxassetid://142376088" -- Raining Tacos
sound.Volume = 1
sound.Parent = workspace
sound:Play()

Use a sound in-game (boombox)

  1. Join a game that has a boombox, radio or car stereo (e.g. Brookhaven, Berry Avenue, Catalog Heaven).
  2. Equip the music item.
  3. Paste the plain number into its input box and press play.

Some games sell the boombox as a game pass and some disable custom audio entirely.

Why some sound IDs stop working: since Roblox's 2022 audio privacy update, uploaded audio can be made private, removed or blocked per-experience. A valid ID may still be silent in a specific game. Default animation IDs are stable.
